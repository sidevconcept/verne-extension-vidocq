= Verne
:lang: fr

Moteur de gabarits textuels compilés pour Java 25, autonome et destiné à l'écosystème Vidocq.
Le nom rend hommage à Jules Verne.

== État du projet

Première tranche du compilateur : gabarits textuels UTF-8, paramètres typés, accès directs aux composants de records, commentaires et échappements.
Les 42 tests de la suite passent, dont les 17 tests métier initiaux. Les classes générées n'exigent que le JDK à l'exécution.
Lire link:docs/fr/modules/ROOT/pages/compilateur-minimal.adoc[le contrat livré et ses limites]. Aucune performance n'est encore revendiquée.

== Installation

Installer un JDK 25 ; la référence du projet est Temurin 25.
Le fichier `.sdkmanrc` déclare Java `25-tem` et Maven `3.9.16` pour les postes utilisant SDKMAN.

[source,shell]
----
git clone --branch fonctionnalite/premiers-tests https://github.com/sidevconcept/verne-extension-vidocq.git verne
cd verne
----

Sur Mac, si plusieurs JDK sont installés, sélectionner Java 25 avant la construction :

[source,shell]
----
export JAVA_HOME=$(/usr/libexec/java_home -v 25)
export PATH="$JAVA_HOME/bin:$PATH"
----

== Vérification

Le lanceur Maven fourni fixe Maven 3.9.16 ; utiliser un JDK 25.
Le premier lancement peut télécharger cette distribution et les dépendances de test.

Sous Windows :

[source,powershell]
----
java -version
.\mvnw.cmd --version
.\mvnw.cmd clean verify
----

Sous Unix :

[source,shell]
----
java -version
./mvnw --version
./mvnw clean verify
----

Résultat attendu : 42 tests, zéro échec, zéro erreur et zéro test ignoré, puis construction des archives.
Ce résultat a été confirmé sur Windows et sur Mac ; les environnements et limites sont consignés dans link:docs/fr/modules/ROOT/pages/compilateur-minimal.adoc[le contrat du compilateur minimal].
Pour relancer uniquement la compilation et les tests, utiliser `./mvnw test` ou `.\mvnw.cmd test`.
Le lanceur Unix est versionné exécutable avec des fins de ligne LF ; en cas de problème, vérifier `git ls-files --stage mvnw` et le montage du répertoire.

Lire link:docs/fr/modules/ROOT/pages/premiers-tests.adoc[la phase rouge historique] et link:docs/fr/modules/ROOT/pages/compilateur-minimal.adoc[la phase verte actuelle]. Un test en échec ne doit plus être considéré normal pour les capacités livrées.
Les rapports se trouvent dans `verne-verification/target/surefire-reports`.
Le compilateur est attendu dans `verne-compilation/target/classes` ; un autre emplacement peut être fourni par `-Dverne.chemin.processeur=...`.
Les journaux sous `target` sont supprimables par `clean` ; ne pas rediriger un journal ouvert vers ce répertoire pendant le nettoyage sous Windows.
